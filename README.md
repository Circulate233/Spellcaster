## 简介
Spellcaster 是 [魔法金属](https://www.curseforge.com/minecraft/mc-mods/manametal) 的 1.7.10 附属模组，添加了两枚核心槽饰品：**命运之轮**与**混沌之轮**。

将技能序列蚀刻进轮盘（允许重复蚀刻），之后只需一个按键，轮盘就会自动选出可释放的技能并施放：
- **命运之轮**：按顺序施放。普通模式跳过冷却中的技能继续往后找；严格模式只认当前刻度，冷却中则直接停止。
- **混沌之轮**：从所有未冷却的技能中随机施放，重复蚀刻的技能被选中概率更高。

同时带有纯客户端模式，此时不需要饰品即可使用。

# Spellcaster

## Overview
Spellcaster is a 1.7.10 addon mod for [ManaMetal](https://www.curseforge.com/minecraft/mc-mods/manametal) that adds two Core slot baubles: the **Fate Wheel** and the **Chaos Wheel**.

Etch a skill sequence into a wheel (duplicates allowed), then a single keypress automatically picks a castable skill and casts it:
- **Fate Wheel**: casts in order. Normal mode skips skills on cooldown and keeps scanning; Strict mode only checks the current slot and stops if it is on cooldown.
- **Chaos Wheel**: casts a random skill among everything off cooldown; duplicated entries are more likely to be picked.

A client-only mode is also provided, which works without the baubles.
